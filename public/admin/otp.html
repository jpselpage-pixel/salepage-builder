ตั้งค่า SMTP (อีเมลจริง)

ใช้สำหรับส่งลิงก์ยืนยันอีเมล และ OTP กู้รหัสผ่านทางอีเมล — ตั้งค่า SMTP ของผู้ให้บริการอีเมล (เช่น Gmail, Zoho, Hosting ฯลฯ) เมื่อครบและปิดโหมด dev ระบบจะส่งอีเมลจริง

วิธีตั้งค่า SMTP ด้วย Gmail (ฟรี):
  1. ใช้บัญชี Gmail ของคุณ (แนะนำสร้างเมล์ใหม่ของร้านค้า)
  2. เปิด การยืนยัน 2 ขั้นตอน ที่ myaccount.google.com/security
  3. สร้าง รหัสผ่านแอป (App Password) 16 ตัว แล้วคัดลอกไว้
  4. กรอก: Host smtp.gmail.com · Port 587 · User = อีเมล Gmail · Password = รหัสผ่านแอป 16 ตัว
  5. กดบันทึก แล้วกด ทดสอบส่งอีเมล เพื่อตรวจ
